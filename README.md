# Вечное 3 сентября

Мемный сайт: отрывной календарь, который сколько ни переворачивай — всё равно 3 сентября.
Обычный статический сайт, без сборки и без офлайн-режима. Хостится на GitHub Pages.

## Что внутри

- Отрыв листа тапом, кнопкой, пробелом или свайпом вниз — лист рвётся по перфорации, со звуком.
- Меняется только день недели. Воскресенье красное, как в настоящих отрывных календарях.
- Иногда мелькает «4» и тут же становится «3». «← Вчера» возвращает лист — и он тоже 3 сентября.
- Лист «стареет»: с 10 отрывов висит криво, с 50 желтеет, со 100 — след от кружки.
- 100 отрывов подряд (не дольше 1,2 с между ними) — календарь падает со стены и его вешают обратно.
- Режимы по реальной дате: обратный отсчёт за 9 дней до 3 сентября; 2 сентября первый лист — «2»,
  календарь нервничает и тикает таймер до полуночи; 3 сентября — «впервые всё сходится».
- Открытка дня: три стиля (блестящая «бабушкина», советская, осенняя), новая каждый день,
  кнопка «Другая». На каждой — плашка с адресом сайта и QR-кодом.
  «Отправить открытку» на телефоне сразу открывает системное меню с картинкой и подписью,
  на компьютере кладёт картинку в буфер обмена.
- Общий счётчик листов всех посетителей (необязательно, через Supabase).

### Проверить режимы без ожидания даты

Добавить к адресу якорь и обновить страницу:

- `#aug29` — тревожный обратный отсчёт по дням
- `#sep2` — последний день лета, таймер до полуночи
- `#sep3` — настоящее 3 сентября

## Файлы

```
index.html          разметка и превью ссылки (og-теги)
css/style.css       стили, светлая и тёмная тема
js/config.js        адрес сайта и ключи Supabase — менять только тут
js/util.js          время, склонения, хранилище, тосты, «поделиться»
js/counter.js       общий счётчик
js/postcard.js      открытка дня
js/app.js           календарь, звук, свайп, серия, режимы по дате
img/                favicon, иконка для iOS, картинка превью 1200×630
supabase.sql        SQL для общего счётчика
```

QR-код рисует `qrcode-generator` с jsDelivr. Если CDN не ответит, открытка выйдет без QR, но с адресом текстом.

## Публикация на GitHub Pages

1. Создать репозиторий `vechnoe-3-sentyabrya` в аккаунте `danya-bit0505` и залить содержимое папки.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Сайт появится на `https://danya-bit0505.github.io/vechnoe-3-sentyabrya/`.

Если имя репозитория другое — поменять адрес в `js/config.js` (`siteUrl`) и в `index.html` (`og:url`, `og:image`).

## Общий счётчик

Без настройки сайт работает, строка «Все вместе оторвали…» просто не показывается.

1. Завести бесплатный проект на supabase.com.
2. SQL Editor → вставить `supabase.sql` → Run.
3. Project Settings → API: скопировать Project URL и `anon` public key в `js/config.js`.

Отрывы копятся пачкой и отправляются одним запросом раз в пару секунд, за раз не больше 200 листов.
Ключ `anon` публичный, его можно держать в репозитории: напрямую писать в таблицу он не даёт,
только вызывать `add_sheets`.

Перед запуском стоит проверить, открывается ли `*.supabase.co` у друзей без VPN.
